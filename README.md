# SpaceX Discounted Cash Flow (DCF) Valuation Model

A comprehensive, fully integrated Microsoft Excel valuation model estimating the intrinsic value of **SpaceX** using the **Discounted Cash Flow (DCF)** methodology.

The model is designed to replicate the workflow followed by investment banking, equity research, and corporate finance professionals while remaining easy to navigate and modify.

---

## Overview

This project forecasts SpaceX's future financial performance, projects free cash flows, and determines enterprise value using a discounted cash flow approach.

The workbook contains interconnected financial statements, dynamic assumptions, valuation schedules, and an interactive dashboard for quick analysis.

---

## Workbook Structure

| Sheet                 | Description                                              |
| --------------------- | -------------------------------------------------------- |
| **Cover**             | Project overview and navigation                          |
| **Assumptions**       | Key operating, financing, and valuation assumptions      |
| **Input**             | Historical financial data and model inputs               |
| **IS Forecast**       | Projected Income Statement                               |
| **BS & CF Forecast**  | Projected Balance Sheet and Cash Flow Statement          |
| **DCF**               | Enterprise valuation using discounted cash flow analysis |
| **Dashboard**         | Interactive summary of forecasts and valuation outputs   |
| **One Page Analysis** | Executive summary of the valuation                       |

## How to Use

1. Open **SpaceX - DCF Model.xlsx**.
2. Update assumptions in the **Assumptions** sheet.
3. Modify historical inputs if required.
4. Review projected financial statements.
5. View valuation outputs in the **DCF** sheet.
6. Explore the **Dashboard** and **One Page Analysis** for a summarized view.
